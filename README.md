# Codex Task Lens

**嵌入 Codex 的任务进度面板，让长任务的进展一目了然。**

Codex Task Lens（任务透镜）计划通过本地 CDP 识别当前对话、注入面板，并读取关联 Task 文档，实时列出已完成与未完成事项。

## 当前状态

项目处于设计阶段，**尚未实现应用代码，也没有可安装的发布版本**。用户已反馈 macOS CDP 可行性验证通过；这不代表本项目功能已完成或已通过真机验收。

## 文档

- [一期 Spec](docs/specs/2026-09-26-task-lens-mvp.md)：产品范围、交互、数据来源、对话绑定、技术边界和验收标准。
- [一期 Task](docs/tasks/task-lens-mvp.md)：可独立验证的任务、依赖、写入边界、联通门禁和执行台账。
- [后续 TODO](docs/TODO.md)：二期整体估算与尚未承诺实施的扩展。

## 一期边界

面向 macOS，独立于 `spec-driven-workflow` 和任何 Skill／Hook。自动发现文档候选，首次确认绑定；文档只读，支持普通 Markdown 勾选清单，不要求特定任务模板。

只展示客观清单与勾选数量，整体进度估算放二期。CDP 不可用时，计划通过复用组件的本地浏览器面板继续手动查看文档。

这是非官方项目，与 OpenAI 无隶属或背书关系。CDP 会开放本机调试能力；即使工具只读，调试端口也不是只读接口。安全边界见 [Spec](docs/specs/2026-09-26-task-lens-mvp.md#8-启动安全与兼容)。
