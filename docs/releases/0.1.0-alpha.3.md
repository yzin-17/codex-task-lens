# Codex Task Lens 0.1.0-alpha.3

## 改动

- 关闭主浮窗时同时取消固定、清除拖动坐标和临时尺寸约束。再次打开时重新锚定当前「进度」入口，不沿用旧位置。
- 主浮窗保持打开期间，切换清单/文档、数据更新及收起章节选择列表仍保留位置；拖动边界与鼠标捕获清理保持。
- PR #3 / #4 已合入 main。后续直接在 main 开发，CI 随 main 推送构建，发布仅由新版本标签触发，不覆盖既有 Release。

## 本地会话扫描现状

Task Lens CLI 已支持 `--session-root <Codex 数据目录> --allow-session-read`，结合 `--workspace <项目目录>` 可从当前对话记录提取授权范围内的 Markdown 候选。未指定时不读取会话记录；不读取 auth.json。

本版本没有增加桌面控制台的会话目录入口。该入口仍待接入，不把统一的「优先显示当前对话线索」提示视为已经启用扫描。项目文档授权与会话记录授权相互独立。

## 安装与限制

提供 macOS arm64 / x64 DMG、ZIP，以及 Windows x64 Setup.exe、ZIP，自带运行环境。升级前退出旧 Task Lens；不需要重启已经启用 CDP 的 Codex。

Mac 为临时签名、未 Developer ID 签名和 Apple 公证；Windows 未签名，可能出现来源提示，不要求关闭系统安全保护。Windows 真实 Codex 内嵌兼容和原一期未完成验收仍保留。

发布门禁仍包含源码回归、三平台构建、打包程序启动/独立清单更新/恢复自检和同提交校验和；它们不替代真实 Codex 全部人工场景验收。
