# Codex Task Lens 0.1.0

## 正式版

0.1.0 是 Task Lens 首个稳定版本。默认发行采用轻量 Agent，通过本机回环 CDP 将任务进度面板接入 Codex，不包含 Electron、Chromium 或 Node.js runtime。

- macOS 与 Windows 分别提供独立 ZIP，解压后可直接启动。
- macOS ZIP 内含 `Codex Task Lens.app`；Windows ZIP 内含 `Codex Task Lens.vbs`。
- 进度入口在 Codex 后续追加工具栏控件时仍保持在工具栏末端；浮窗完成锚定前保持隐藏，避免短暂显示在错误位置。
- 正式版本以稳定 Release 发布；带 `-alpha` 等预发布后缀的版本继续以 prerelease 发布。

## 运行要求

- 本机安装 Node.js 22.20 或更高版本。
- 从本页按系统下载 `Codex-Task-Lens-0.1.0-mac.zip` 或 `Codex-Task-Lens-0.1.0-windows.zip`，解压后直接运行对应入口。无需安装 pnpm、Git 或源码。
- 保留现有 Task Lens 设置、绑定与状态目录；程序不强制结束 Codex。

## 发布验证

版本标签工作流在创建 Release 前运行 lint、typecheck、测试、Node 22.20/24 Agent bundle 验证，以及 macOS 与 Windows 原生打包和 direct-launch smoke。Release 附件仅包含两个平台 ZIP。
