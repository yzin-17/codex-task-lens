# Codex Task Lens 0.1.0-alpha.8

## 运行要求

- Node.js 最低版本统一为 `>=22.20.0`，不设置 Node 上限；不再把 Node 24 单独列为受支持范围。
- Agent bundle 继续以 Node 22 为构建目标；CI 至少覆盖 Node 22.20 与 Node 24。

## macOS 双击体验

- `.app` 外壳改为几十 KB 的原生 Universal launcher（arm64 + x86_64），不再用长期存活的 shell 作为 App 主进程。
- 原生 launcher 调用轻量 shell 后立即退出，后台 Agent 独立运行；LaunchServices 因此可以可靠处理后续再次双击。
- Task Lens 已运行时，再次双击会提示“已在运行”并切回 Codex，不会启动第二个长期 Agent。
- Codex 已普通运行且没有 CDP 时，会明确提示先正常退出 Codex，再双击 Task Lens；不会强制重启正在工作的 Codex。
- 启动时会显示“正在启动 Codex 并加载 Task Lens…”或“正在连接 Codex…”通知。

## App 图标

- 新增专用 Task Lens 图标：深色圆角底、金色进度/透镜、清单勾选语义。
- macOS 打包为 `AppIcon.icns` 并写入 `CFBundleIconFile`；Windows 包附同源 PNG 资源。
## Electron 清理

- 删除旧 Electron 控制台、`electron-builder`、`tools/desktop`、desktop tests、legacy Electron workflow 与旧桌面发行文档。
- `package.json` 不再保留 Electron main / build / smoke 脚本；macOS 文件选择器也移除了仅供 Electron 注入的 override。
- 仓库现在只有轻量 Agent 发行链路。
