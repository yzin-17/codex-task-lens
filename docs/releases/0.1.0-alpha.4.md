# Codex Task Lens 0.1.0-alpha.4

## 改动

- 桌面控制台新增“选择会话目录／停用扫描”。会话扫描默认关闭；选择目录后才启用现有 SessionRecords，并在停用后立即重启 Task Lens 运行时，不重启 Codex。
- 本地会话扫描只读取所选根目录下 `sessions/` 与 `archived_sessions/` 的受支持 rollout JSONL，提取当前对话里明确出现的 Markdown 路径；不读取 `auth.json`，也不会自动获得这些 Task 文档的读取权限。
- 章节范围搜索列表改为浏览器 top-layer popover，根据触发器、视口和固定确认底栏自动向上或向下展开，长列表在自身滚动，不再被文档滚动区或底栏裁切。
- 已选文档列表改为仅在相邻文档之间显示分隔线；只有一份文档时不再出现末尾多余横线。
- 保留上一版的关闭浮窗取消固定和恢复默认位置行为。

## 安全与限制

- 会话目录授权与 Task 文档读取授权相互独立；会话线索只影响候选排序/发现，不能绕过文件授权。
- 不发送消息、不修改 Task 文档、不读取登录凭据、不自动重启 Codex。
- macOS 仍未完成 Developer ID 签名／Apple 公证，Windows 仍未签名，系统可能显示来源提示；不要关闭系统安全保护。
- Windows 打包与独立功能已验证；真实 Windows Codex Desktop 内嵌兼容仍以单独真机验收为准。
