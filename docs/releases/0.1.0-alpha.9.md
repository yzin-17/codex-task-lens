# Codex Task Lens 0.1.0-alpha.9

## Agent 生命周期

- 内嵌面板新增 `设置 → 退出 Task Lens`，需要二次确认。
- 退出只停止 Task Lens：CDP bridge、文件 watcher、本地 server、SessionRecords 与 supervisor 会 graceful shutdown；Codex 本身不会关闭。
- 退出完成后 `agent.lock` 被删除；之后再次双击 Task Lens 即可恢复注入。
- standalone Web 面板不能调用 shutdown，避免普通本地页面控制后台 Agent 生命周期。

## Codex 关闭后的重新启动

- supervisor 新增本地 `agent.control.json` 控制通道。
- Agent 已运行但 Codex 已退出时，再次双击 App 不再要求先结束 Agent：启动入口向现有 supervisor 发送 `restart`。
- supervisor graceful 停止旧 CLI，再以同一配置重新启动 CLI；因为 CLI 保留 `--launch-codex`，Codex 会以回环 CDP 参数重新启动。
- restart 前后 supervisor PID / `agent.lock` 保持不变，不创建第二个长期 Agent。
- Windows 直接启动入口同样会向活跃 supervisor 发送 restart，而不是创建重复实例。

## 安全边界

- shutdown 必须来自当前注入 pane、正确 nonce 和显式 `consent:true`；成功 reply 发给 renderer 后才触发进程退出。
- 本地 control 文件只影响已经持有用户级 lock 的 supervisor，不提供网络控制接口。
- 退出 Task Lens 不会关闭 Codex 已开放的 CDP；如需关闭调试端口，需要正常退出 Codex 后从普通 Codex 入口重新启动。
