# Codex Task Lens 0.1.0-alpha.6

## 默认发行改为轻量 Agent

- GitHub Release 默认只发布 `Codex-Task-Lens-0.1.0-alpha.6-agent.zip`，不再随 tag 打包 Electron / Chromium。
- Agent 的 Node host 与生产依赖 bundle 为单个 `index.mjs`；注入 UI 与独立面板作为静态资产随包提供。
- 本机以 `alpha.6` 版本号实测：staging `751,613` bytes（约 0.72 MiB），ZIP `245,276` bytes；正式 GitHub Release 由干净 runner 重建后的 ZIP 为 `239,618` bytes（约 234 KiB）。
- 轻量版需要本机已有 Node.js 24.x；不需要 pnpm、Git，也不需要用户手工执行启动命令。

## 安装与启动

- macOS：解压后双击 `install.command`，安装器创建 `~/Applications/Codex Task Lens.app`；之后双击该 App 即可。
- Windows：解压后双击 `install.cmd`，安装器创建桌面与开始菜单快捷方式，并通过隐藏 PowerShell launcher 启动 Agent。
- 启动器复用现有 `desktop-settings.json`，默认端口 9341、默认启用 `~/.codex` 会话扫描；显式停用扫描和自定义路径继续保留。
- 若 Codex 已普通运行且未开放 CDP，不会被强退或接管；正常退出后再从 Task Lens 入口启动。

## 对话 Task 候选

- 适配当前 Codex `custom_tool_call: exec` rollout 格式，可从 `tools.exec_command` / 包装内 `apply_patch` 提取 Markdown 路径。
- 对话中明确出现且真实存在的 `docs/tasks/**`、`tasks/**`、`TASKS.md` 可在未授权项目目录时直接显示为“待授权”。
- 候选阶段只检查精确文件存在性/类型，不读取正文、不扫描父目录；点击“添加”才授权读取该文件，最后仍需确认绑定。
## 平台能力

- Windows 的“选择文件…”改用系统 PowerShell / WinForms 文件选择器，不再依赖 Electron。
- CLI 的 Codex 应用发现改用通用 macOS / Windows 适配；轻量 bundle 不因平台切换加载错误入口。
- 修复单文件 bundle 中 standalone runtime 误判为直接入口的问题，避免额外启动独立本地服务。

- CI `36307522717`：Ubuntu 与 macOS 完整回归通过。

## 安全与限制

- 轻量包不携带 Node runtime，因此安装时会拒绝非 Node.js 24.x 环境。
- 会话扫描仍不读取 `auth.json`；Task 文件在点击候选“添加”前不读取正文。
- 旧 Electron 源码与手动 workflow 暂时保留作为兼容构建，但不会出现在本版本默认 Release。
- Windows 真实 Codex Desktop 的完整多窗口/侧聊验收仍沿用现有兼容性边界；CI 安装 smoke 不替代真实账号验收。
