# Codex Task Lens 0.1.0-alpha.7

## 发行方式调整

- macOS 与 Windows 现在分别发布 `Codex-Task-Lens-0.1.0-alpha.7-mac.zip` 和 `Codex-Task-Lens-0.1.0-alpha.7-windows.zip`；正式 Release 大小分别为 `238,469` bytes 与 `235,519` bytes。
- macOS 解压后直接双击 `Codex Task Lens.app`；Windows 解压后直接双击 `Codex Task Lens.vbs`。
- 不再运行安装脚本、不再复制到用户目录、不再创建桌面/开始菜单快捷方式；解压目录本身就是程序。
- 两个平台都继续使用同一份轻量 Node Agent + CDP 注入 UI，不包含 Electron、Chromium、Node runtime 或 `node_modules`。

## Node 版本

- 取消 Node 24 独占要求，正式支持 Node.js `22.20+` 与 `24.x`。
- 当前没有 Node 24 专属运行时依赖；最低版本主要由全局 WebSocket 与 `path.matchesGlob` 的稳定可用版本决定。
- CI 同时在 Node 22.20 与 Node 24 上验证 Agent bundle；macOS/Windows 直接启动 smoke 使用最低支持版本 Node 22.20。

## Codex 会话目录

- 默认会话扫描优先使用绝对路径 `CODEX_HOME`；未设置时使用当前用户 Home 下的 `.codex`。
- Windows 上即通常的 `%USERPROFILE%\.codex`；不是 Unix 专属路径。
- 自定义 `sessionRoot` 与显式“停用扫描”设置仍优先于默认值。

## 安全与限制

- 轻量包依赖系统已有 Node；找不到受支持 Node 时，平台入口会给出错误提示而不是下载或执行未知运行时。
- macOS `.app` 仍不是 Developer ID 公证应用；Windows `.vbs` 也不是签名 EXE。不要通过关闭系统安全功能绕过来源提示。
- Windows 真实 Codex 多窗口/侧聊兼容仍以既有真机验收边界为准；CI 的 Windows runner 只验证直接启动、文件选择及 Agent 行为。
