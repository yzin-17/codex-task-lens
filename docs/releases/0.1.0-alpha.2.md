# Codex Task Lens 0.1.0-alpha.2

桌面预发布：自带运行环境，无需安装 Node、pnpm 或 Git。Mac 下载对应 arm64（Apple Silicon）或 x64（Intel）的 DMG/ZIP；Windows x64 下载 Setup.exe 或便携 ZIP。

## 使用

安装/完整解压后双击 Codex Task Lens。控制台自动连接已配置端口，默认 9341。已有其他 CDP 工具时填相同端口；不强制重启 Codex。未开放端口时，请等待任务结束、正常退出 Codex，再点击“调试启动”。

“独立清单”不依赖内嵌连接成功。项目目录与 Markdown 仍由用户选择；工具仅按文档勾选展示进度，不修改业务文件、不读取登录凭证。关闭控制台后可从菜单栏/托盘返回，退出 Task Lens 才停止监控。

## 变更

- 候选文档只在相邻项之间分隔，不出现末项与手动添加的双横线。
- 本机目标锁避免新版 Task Lens 在相同 Codex 页面互相替换；其他 CDP 工具独立连接。旧 CLI 版本不遵守新锁协议，先停止旧版 Task Lens，再运行桌面版。
- Windows 应用发现、OpenAI 发布者签名、端口进程/回环验证及原生 Markdown 文件选择。
- 新桌面控制台、重复启动唤回、托盘、连接/停止和独立窗口。

## 验证与限制

附件 packaged-smoke JSON 记录原生 runner 上实际打包应用的启动、隔离 preload、临时 Markdown 绑定/原子更新/重启恢复；测试时 PATH 不提供外部 Node/pnpm。SHA256SUMS 对应附件校验值。

**Mac 为临时签名、未完成 Developer ID 签名与 Apple 公证；Windows 未签名。系统可能提示来源未知。不要关闭 Gatekeeper、SmartScreen 或其他系统保护；需要无提示安装的环境请等待正式签名版本。**

Windows 真实 Codex Desktop 的界面/签名兼容仍需用户环境验收，CI 不包含真实账号会话。签名或页面结构不受支持时，内嵌连接保守失败，但独立清单仍可使用。此版本不是原一期全部真机门禁完成声明，也不自动合并仓库 PR。

CDP 为高权限本机调试入口，不向公网暴露。退出 Task Lens 不会关闭 Codex 的调试端口；需正常退出调试启动的 Codex，再从普通入口启动。
