# Codex Task Lens 0.1.0-alpha.5

## 改动

- 桌面版“当前对话文档线索”改为默认启用：未配置时使用 `${HOME}/.codex`，旧配置没有扫描状态字段时也按启用迁移。
- 控制台保留“更换目录 / 停用扫描”。用户明确停用后写入 `sessionScanEnabled=false`，之后重启仍保持关闭；再次选择目录会重新启用。
- 会话扫描仍只读取所选根目录下 `sessions/` 与 `archived_sessions/` 的受支持 rollout JSONL，只提取明确 Markdown 路径，不读取 `auth.json`，也不授予 Task 文档读取权限。
- “可添加文档”无项目授权时，原本嵌在提示文字里的“授权项目目录”改为明显按钮；点击后切换到目录模式、滚动并聚焦路径输入，但不会自动授权任何路径。
- 继续包含 alpha.4 的章节范围 top-layer 浮层、单文档无多余分隔线、关闭浮窗取消固定并恢复默认位置等修复。
