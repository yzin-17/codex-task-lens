# 工具栏浮窗与多 Markdown 修订验证

修订范围：[Spec §12](../../specs/2026-09-26-task-lens-mvp.md#12-已批准调整工具栏浮窗与多文档2026-09-26)；[修订任务](../../tasks/toolbar-multidoc.md)。产品代码基线 `1581a232950497bfd88adbfb0d7b6eb76395ffb8`。

## 已实现

入口移入输入框底部左侧工具栏，位于权限按钮之后。入口直接显示「任务 已完成/总数」；关闭浮窗仍订阅更新。点击打开原生 top-layer popover，不再向宿主文档流插入展开式表单。

浮窗提供「清单／文档」视图，每份文档保留未完成和已完成两组；两组默认展开。支持 Escape、外部点击与关闭按钮，优先上方并避让视口。移除重复标题、状态和冗长页脚，保持轻量。

支持系统多选入口及每行一个路径，最多 16 份 Markdown；逐文件授权／预览／章节范围、去重和错误，最终一次确认整组。管理文档支持取消和逐项移除，失败不部分保存。schema v1 单文档保持 ID／范围／授权／版本并读为一项数组，后续成功事务才写 schema v2。

实际设备 macOS 26.6.2／arm64、Codex 26.924.22138，Node 24.18.0、Corepack pnpm 10.28.2。通过已授权远程终端运行编译后的 production bridge、service 与独立 CDP observer；不修改业务 Task，也未重启 Codex。

## 更新时延原始值

同一 Mac、两份临时文件绑定时，针对其中一份 1000 项 Markdown 执行 20 次原子保存，以第二个 CDP 客户端读取实际可见计数，单位 ms：

`434.21, 397.11, 372.15, 396.38, 446.25, 343.38, 353.17, 362.66, 367.99, 376.18, 357.64, 377.03, 365.12, 373.16, 465.71, 376.36, 363.48, 357.73, 364.68, 354.98`

nearest-rank p95 = **446.25 ms**；只适用于这组实际环境与采样，不推算任务剩余时间，也不是所有系统的延迟保证。结构化结果见 [toolbar-multidoc-mac.json](toolbar-multidoc-mac.json)，仅含版本、构建指纹、布局、布尔断言和时延，没有原始会话 ID／正文／文件绝对路径。

初轮真机检查发现 Escape 关闭后焦点被宿主抢回输入框，不能以浏览器 fixture 的成功掩盖该问题。已改为原生 popover invoker，并在关闭过渡后恢复入口焦点；外部点击不执行此恢复。修复后实际再次验证关闭、焦点恢复、文件生命周期、时延与清理。回归同时模拟宿主拦截 Escape 后异步聚焦输入框。
