# T05：授权路径策略

状态：已完成。实际代码基线与环境见 [验证索引](README.md)。

`src/files/path-policy.ts` 只读取明确授权的本地 Markdown，复核规范化路径、realpath、文件类型、符号链接和读取前后文件版本。只授权文件不包含相邻文件；同相对路径的不同 worktree 不合并。

复现：`pnpm exec vitest run tests/unit/path-policy.test.ts`。全量 CI 在 Linux 与托管 macOS 执行 5 项临时目录测试，验证前缀混淆、越权路径／链接、链接重定向、中文空格路径、未知／非 Markdown 文件和身份区分。

数据访问策略不等于抵御已经控制本机账户的恶意软件；未读取用户真实目录。
