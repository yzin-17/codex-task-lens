# T13：独立监控应用服务

状态：已完成。代码与环境见 [验证索引](README.md)。

`src/host/lens-service.ts` 组合真实授权、预览、CAS 绑定、文件流与候选。预览只保存有时限的证明元数据，确认时复核文件版本；同文件监听共享、不同 monitor 数据隔离，异步响应检查 generation／bindingVersion。

复现：`pnpm exec vitest run tests/integration/lens-service.test.ts tests/integration/shared-grant-revocation.test.ts`。8 项全量 CI 用例覆盖双绑定、过期预览、版本冲突、重绑、日志失败降级、实际存储重启、资源释放，以及授权失效后的跨 monitor 缓存隔离。

修复：已失效授权的 monitor 只保留自己的最后合法快照，不能借另一份有效授权继续收到更新。该服务本身不接 HTTP、DOM 或 Codex。
