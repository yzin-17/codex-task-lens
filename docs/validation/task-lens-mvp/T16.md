# T16：候选选择与确认绑定

状态：已完成。基线与实际浏览器环境见 [验证索引](README.md)。

`BindingPicker` 提供文件／目录绝对路径输入和明确只读授权、候选来源与不完整提示、整篇／章节预览、确认／更换／解除和取消。预览晚到响应不会覆盖新选择，确认携带预览时的绑定版本，取消不提交绑定。

本期支持路径输入而非系统原生 picker；生产文件访问与持久化已由 T17／I1 接线验证。
