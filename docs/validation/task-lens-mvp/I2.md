```bash
pnpm build
pnpm doctor -- --cdp-port 9341
pnpm test:mac -- --enable --probe-only --cdp-port 9341
pnpm start -- --cdp-port 9341 --workspace "/实际测试项目的绝对路径"
```

在专用测试项目中创建两个普通 Markdown 文档，勿选择正在执行的生产任务。不要为此关闭运行中的 Codex。没有调试端点时，等待合适时间再由用户明确正常退出／调试启动。
