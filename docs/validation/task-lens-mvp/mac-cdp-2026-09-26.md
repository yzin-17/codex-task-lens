## 修复真实兼容缺陷

macOS 的 lsof 将一个 socket 同时报告在 Codex 主进程和官方 `SkyComputerUseService` 下，二者具有相同 socket device，辅助进程是同用户的直属子进程。旧实现要求所有监听记录只有一个 PID，因此拒绝了这个真实端点。

新逻辑仍要求唯一已签名 Codex 主进程；额外监听者必须共享主进程的同一 kernel socket、同用户、直接父子关系、精确辅助进程名，并通过 OpenAI 签名及 `com.openai.sky.CUAService` identifier 检查。HTTP 前后重新核对完整监听集合及身份；没有忽略冲突、任意放行进程或改写应用。
