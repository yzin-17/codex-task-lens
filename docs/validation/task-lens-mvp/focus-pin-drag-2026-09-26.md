# 表单焦点、进度圆环与固定拖动验证

范围：[Spec §13](../../specs/2026-09-26-task-lens-mvp.md#13-进度入口焦点与可固定拖动浮窗2026-09-26)；[修订台账 F1–FG](../../tasks/toolbar-multidoc.md)。产品代码 `8767f9df49727e26fce4663c21d001dce26348b5`。

## 根因与实现

真实 Mac 点击多路径 textarea 后，焦点从自有按钮转入宿主 ProseMirror，textarea 没有 disabled。此前只隔离 click/input/键盘，未隔离 pointerdown/mousedown 等先于 click 的事件。临时增加自有宿主节点的冒泡隔离后，真实点击能产生 textarea focusin 并维持焦点；最终代码隔离自有指针、鼠标、焦点和表单事件，保留控件默认行为，不删除宿主监听器。

入口改成「进度 已完成/总数」，圆环按完整且已同步的勾选比例填充；未绑定、零任务、缓存或部分数据不绘制虚假有效比例。固定按钮带 aria-pressed，固定后外点及宿主输入不收起；取消固定恢复外点关闭。使用 manual top-layer popover，自有关闭逻辑不会因固定切换而重建文档草稿。Esc 在 select 内留给原生下拉，在固定浮窗外不劫持宿主，在浮窗内仍可关闭。

标题栏支持指针拖动与拖动柄方向键移动。坐标约束到当前输入区所属对话列与可见视口的交集；数据更新不回弹，缩小视口重约束。关闭、失焦、取消指针和卸载释放捕获。固定/位置只存在当前挂载的对话视图；切换销毁，不承诺跨应用重启保存。
