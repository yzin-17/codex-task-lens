# 关闭浮窗位置重置与 main 集成

实现提交：`b0dd8944e511b85268f14b614e056c2544c25fe2`。

## 行为

主浮窗的原生 beforetoggle 关闭事件立即清除位置、临时尺寸与拖动捕获。下次打开重新根据当前进度入口定位，同时沿用关闭取消固定的行为。保持打开时的数据刷新、布局约束、内部章节列表与标签页切换不触发重置。

原生关闭后快速立即重开时，额外的下一帧定位保证 toggle 合并也不会保留旧坐标。关闭期间的 ResizeObserver 不再重新写入旧位置。
