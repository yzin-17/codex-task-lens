## 1. 背景与已确认决策

执行长任务时，即使已有 Task 文档，用户也难以持续看清已完成和未完成的具体事项。Codex Task Lens（任务透镜）通过本地读取文档，在当前 Codex 对话中显示实时清单。

本期采用以下边界：

1. **独立工具**：不依赖 `spec-driven-workflow`、其他 Skill、模型主动登记命令或 Hooks；不修改用户的编排规则。
2. **macOS 优先、CDP 内嵌**：通过 CDP 识别对话并注入面板，不修改官方 `.app`、`app.asar`、签名、登录文件或模型配置。
3. **文档是任务状态来源**：一期展示完成数量和已完成／未完成列表，不估算工作量、整体完成百分比或剩余时间。
4. **自动发现，首次确认**：工具寻找候选 Task 文档，用户确认绑定；以后按对话自动恢复，不静默换绑。
5. **核心可独立运行**：CDP 不可用时，可以在本地浏览器面板手动选择文档继续查看；不在一期增加原生菜单栏 App 或另一套桌面壳。

2026-09-26，用户在本次需求讨论中反馈 Mac 验证已通过。将此作为 CDP 路线可行的输入，不重复安排“是否能实现”的探索。该反馈未提供具体 macOS／Codex 版本、选择器或测试产物；实施时补录兼容基线和脱敏样例，不能把它当作本项目已通过端到端验收。

### 1.1 实施细化：适配合同与真机证据分离

已核对的上游源码常量、协议文档和明确标记的合成 fixture 形成 M2，允许实现会话记录、应用校验、DOM 识别与组合入口；不将 T02 的用户资料缺失误当作所有代码无法推进。具体来源见 [适配合同](../compatibility/adapter-contracts.md)。T02 仍记录实际版本与输入，I2 仍验证用户 Codex 中的完整流程；两者不以托管 macOS／Chromium 测试代替。

## 3. 用户流程与交互

### 3.1 首次使用

启动本地进程后，优先连接用户指定或工具记录的可信本机 CDP 端点。没有可用端点时打开独立面板并说明原因；用户可以继续监控文档，或显式选择调试启动 Codex。

进入一个可识别对话后，先恢复该对话的已有绑定。未绑定时列出候选的标题、相对路径、工作目录、勾选数量和发现来源。用户选择文档、预览计数范围并点击“绑定到当前对话”；无法发现候选时可输入本地绝对路径。选择文件不等于上传文件。

工作目录不能确认时，先让用户选择／输入目录，或者仅授权一个具体文件。不默认扫描整个用户目录，也不把文件父目录自动当作已授权的项目根目录。

### 3.2 日常查看

内嵌入口放在输入框底部左侧工具栏、权限按钮之后，显示 `任务 3/6`。点击打开锚定浮窗，不再内联撑高输入区。首次展开时“未完成”和“已完成”两组均展开；各组可以独立折叠。独立面板默认展开清单。不得只显示完成数而隐藏已完成事项。

```text
任务清单                              3 / 6 已完成
当前对话 · 工作目录 · docs/tasks/example.md

未完成 · 3
○ T4  更新并推送 PR，确认 CI
○ T5  构建并验证测试镜像
○ T6  构建并交付测试包

已完成 · 3
✓ T1  定位错误传播路径
✓ T2  实现友好提示与回归测试
✓ T3  运行测试和生产构建

最近任务变化：2 分钟前       查看原文    更换文档
```

每项显示标题、可用的任务 ID、勾选状态及所属分组；点击展开该项的原文说明、执行记录和验证信息。打开原文使用已经授权的文件路径；提供复制路径与行号作为编辑器不支持行跳转时的退路。

组内保持原文顺序。明确识别到某一项状态变化时可以短暂高亮，但不抢焦点、不自动滚动；切换文档不播放“任务刚完成”动画。键盘能够访问所有操作，状态不只靠颜色区分，支持浅色与深色。

更换／解除绑定是显式操作；取消选择不改原绑定。无额外全局“保存”按钮，绑定确认成功即持久化，失败则保留原状态。新发现的文件只能提示候选，不能覆盖已确认的绑定。

### 3.3 无对话与降级

首页或身份不明确时，内嵌面板显示“未识别到当前对话”，不显示其他对话的清单。独立面板可选择已有绑定或一个独立文档；独立文档使用独立监控标识，不伪造 `threadId`。

CDP 断线、选择器不兼容、会话日志缺失不应破坏已保存绑定和文件监控。独立面板必须明确区分“手动查看的文档”和“自动跟随的对话”。

## 4. 文档解析与计数契约

### 4.1 支持范围

使用支持 GFM task list 的 Markdown AST 解析器并保留源位置，不用全文件正则计数。GFM 明确定义了勾选标记与嵌套任务列表，见 [GFM 规范 §5.3](https://github.github.com/gfm/#task-list-items-extension-)。

- `[x]`／`[X]` 对应已完成，`[ ]` 对应未完成；有序／无序列表均支持。
- 只计入所选范围内的**叶子勾选项**。含后代勾选项的父项作为分组，不与子项重复计数；仅含普通说明子列表的任务仍是叶子。
- 代码块、行内代码、引用块、HTML 块中的示例不计数；普通行中的 `[x]` 字符不是任务。
- 支持无 ID 和重复标题。显式 ID 只作显示信息，不作为合并依据；缺失时用本次解析的结构位置生成行标识，不能声称它跨重排永久稳定。
- 一期不凭标题判断某项是业务任务还是验收项：选中范围内符合语法的叶子项均计数。文档含无关检查清单时，由用户缩小章节范围，不用隐式语义过滤。

默认预览整份文档，可以选择一个标题章节（直到下一个同级或更高层级标题）。范围保存标题层级路径与同名出现序号，不保存固定行号；章节消失或定位不再唯一时提示重新选择，不退回整篇计数。

### 4.2 状态与诚实展示

```text
completed = 已勾选叶子项数
incomplete = 未勾选叶子项数
total = completed + incomplete
```

一期不显示百分比进度条。“进行中／验证中／阻塞”仅可来自任务直属说明中的明确 `状态：` 或 `Status:` 字段；支持值固定为 `进行中 / in_progress`、`验证中 / validating`、`阻塞 / blocked`，其他文本仅按原文展示。多个冲突字段不生成状态标签。附加状态不改变归组和计数；已勾选但仍标阻塞时显示文档状态冲突，不替用户修正。

当 `total = 0` 时显示“所选范围没有任务清单”，不是完成。当 `total > 0` 且全部勾选时显示“清单已全部勾选”，不是“项目已验收”。父项勾选与子项不一致时可以提示结构不一致，但仍按叶子规则计数。

文档没更新，工具就不知道实际代码进展。工具不扫描代码推断完成，也不保证 `[x]` 对应的实现真实通过验证。

## 5. 对话身份、候选发现与绑定

### 5.1 两种身份分开管理

**持久身份**为 `(sourceId, threadId)`。`sourceId` 标识本机 Codex 数据源／profile，由经确认的数据目录或独立配置标识生成；不能用临时端口或窗口 ID 代替。绑定保存 `workspaceRealPath`（可为空）、`documentRealPath`、显示路径、文档范围、绑定版本和确认时间。确认、更换与解除使用 expectedBindingVersion 做条件更新；旧版本操作返回冲突，不覆盖其他窗口的新绑定。

**展示身份**为 `(connectionId, targetId, executionContextId, paneId, generation)`。每个可识别对话区域分别关联持久身份，导航、切换、上下文重建时更新 `generation`。不能维护一个被所有窗口覆盖的全局 `currentThreadId`。

DOM 适配优先读取已验证的对话区域属性；参考项目中的 `data-above-composer-conversation-id`、`data-conversation-id`、`data-thread-id` 是待按版本核对的候选，不是官方稳定契约。选择器隔离在 Codex adapter，不能散落进业务或 React 组件。

只接受明确归属于当前输入区／对话区域的唯一标识。多个候选无法消歧时返回 `unknown`；不选最后一个节点、不按标题匹配、不使用最近有日志活动的会话顶替。侧聊或子代理无法独立识别时明确不可用，不挪用主对话身份。

### 5.2 候选获取顺序

| 来源 | 用法 |
| --- | --- |
| 已确认绑定 | 立即恢复并校验，不等待日志扫描 |
| 匹配当前 `threadId` 的本地会话记录 | 提取明确 Markdown 链接、路径，以及已支持格式的文件读取／写入路径线索 |
| 已授权工作目录扫描 | 默认扫描 `docs/tasks/**/*.md`、`tasks/**/*.md`、`TASKS.md`，允许配置其他 glob |
| 手动路径 | 校验、授权、解析并预览后绑定 |

默认会话数据根来自显式配置；未配置时可探测 `CODEX_HOME` 或 `~/.codex` 的位置，读取记录前须取得该数据源授权，找不到即降级。先用文件名／索引缩小记录范围，再核对记录中的会话身份；不能仅凭文件名或修改时间认定匹配。读取工作目录要尊重已验证格式中的上下文变化；相对路径仅在对应事件的基准目录明确时解析。

只适配已固化样例的记录格式。解析结构化字段和有限的明确路径，不执行日志里的命令，不展开任意 shell 表达式；`cd`、脚本或变量导致路径有歧义时不猜。日志格式不是稳定接口，解析失效必须回退手动路径／目录扫描，见 [官方 transcript 说明](https://developers.openai.com/codex/hooks/)。

同一实际文件的线索合并为一个候选并保留来源；来源优先级只影响排序，不意味着自动绑定。最近修改时间仅辅助排序。没有发现结果只表示“未发现”，不表示该对话没有 Task 文档。

首次只索引已配置的数据源，命中后增量读取相关记录。扫描可取消，忽略 `.git`、依赖目录、构建目录和默认归档目录；不跟随越出授权根的符号链接。文件不存在、无权限、不含有效清单或超限时给出对应原因，不当作零进度。

### 5.3 跨目录与绑定生命周期

一份文档可被多个对话绑定；每份实际文件只建立一个底层监听，解析结果可按范围复用。同仓库不同 worktree 的同名文件必须分离。分叉的新会话不自动继承父会话绑定，可以推荐后由用户确认。

绑定文件移动或归档后标记源不可用，不按同名文件自动重绑。原授权路径发生正常原子替换可以重新读取；符号链接的实际目标变到授权外必须拒绝，要求重新授权。

持久化只写工具自己的应用数据目录 `~/Library/Application Support/CodexTaskLens/`。JSON 使用版本字段、原子替换和受限权限；损坏时保留原文件并给出恢复入口，不静默覆盖为空。工具仅允许一个状态写入进程，第二个实例明确退出或连接已有实例，不竞争覆盖。

## 6. 文件同步、异常与资源边界

监听源文件及必要父目录，处理编辑器的临时文件加 rename 保存。Node 文档说明 macOS 上仅监听旧 inode 可能漏掉删除重建后的变化，因此不能只创建一次文件 watcher 后永久复用，见 [fs.watch caveats](https://nodejs.org/api/fs.html#caveats)。

读取流程为：合并事件、等待短暂稳定、读取并复核文件版本、发布不可变快照。检测到连续写入时重试；这不等于能识别任意 Markdown 的编辑事务。短暂截断不应立即闪现“全部完成”。

快照包含 `revision`、`lastReadAt`、`lastTaskChangeAt` 和来源状态。`lastTaskChangeAt` 只在清单语义变化时更新；长时间没有勾选变化不等于监听故障。读取失败可以保留最近成功快照，但必须标“缓存／源不可用”，不能把它显示为当前有效进度。

默认限制：单文档 2 MiB、5,000 个叶子项；候选扫描最多检查 2,000 个 Markdown 路径，达到上限显示“结果不完整，可缩小范围”。会话记录流式读取，单条记录上限 1 MiB；未知／损坏／超限记录跳过并提供诊断计数，不持久化正文。正在写入的半行等待补全，文件轮转／截断重新定位，不永久丢失追加记录。

实现补充的防放大边界：源文档最多 50,000 行、10,000 个标题、单标题 512 字符；标题展开元数据最多约 4 MiB、解析任务数据最多约 8 MiB；嵌套深度最多 64 层。超限必须明确报告 unsupported，不静默截断任务。重放缓存同时限制条目数与约 8 MiB 序列化大小，预览票据只保存元数据；这些是安全资源上限，不是性能验收通过证据。

性能验收目标（不是既有测量）：在记录过配置的 Mac、本地磁盘、单文档不超过 1 MiB／1,000 项下，20 次稳定保存到可见更新的 p95 不超过 1 秒；事件丢失时用不高于每 5 秒一次的轻量版本核对，变化在 6 秒内恢复。切换、解绑、页面销毁和停止工具后释放不再使用的监听、计时器、CDP 订阅及端口，不循环扫描全仓库来维持刷新。

## 7. 技术结构与接口边界

### 7.1 技术基线

采用 Node.js 24、TypeScript、pnpm；React + Vite 构建共享面板；使用 GFM AST 解析库、Vitest 和 Playwright。具体依赖版本在基础任务中锁定到 lockfile，不使用浮动 `latest`。Node 24 在本 Spec 编写时为 LTS，见 [Node 发布表](https://nodejs.org/en/about/previous-releases)。本期不引入 Electron／Tauri 壳、数据库、队列或插件框架。

```text
src/core/                  # 文档解析与业务规则，不依赖 Codex / DOM / HTTP
src/contracts/             # 共享类型、消息校验、错误语义
src/files/                 # 授权路径、稳定读取、文件监听
src/store/                 # 配置与绑定持久化
src/discovery/             # 候选合并、扫描与解释
src/adapters/codex/         # 只读会话记录、CDP、DOM 兼容适配
src/host/                  # 应用编排、独立面板传输、CDP bridge
src/ui/                    # TaskPanel / BindingPicker 及两种入口
src/platform/macos/        # 应用发现、端点归属校验、显式启动
src/cli/                   # 生命周期与运行入口
```

依赖方向为外层调用 core／contracts，core 不反向引用适配层。共享面板只消费规范化快照与有限操作接口，不读取宿主 React 内部状态，不包含任意文件访问能力。

### 7.2 最小消息契约

`protocolVersion = 1`。请求携带 `requestId`、目标监控身份及适用的 `generation`／`bindingVersion`；响应和快照回传同一关联信息。过期响应必须丢弃，切换后立即清除旧视图，不能等待旧查询返回再切换。

| 契约 | 必要内容 |
| --- | --- |
| `MonitorRef` | 明确区分 `thread(sourceId, threadId)` 与 `standalone(id)` |
| `Binding` | 授权引用、实际路径、范围、绑定版本、确认时间 |
| `SessionHints` | `ready / unavailable / unsupported`、可选 cwd、带来源和基准目录的明确路径线索；不含完整正文 |
| `Candidate` | 候选 ID、路径、工作目录、来源列表、预览计数、诊断 |
| `TaskItem` | 本快照内唯一行标识、可选显式 ID、标题、checked、源范围、分组、原文详情、可选明确状态 |
| `TaskSnapshot` | 监控身份、绑定版本、内容 revision、两组条目、计数、时间、来源状态、诊断 |
| `ViewState` | 另行表达连接与识别状态；不能用“未连接”冒充零项任务 |

只暴露 `listCandidates`、`previewDocument`、`confirmBinding`、`confirmBindings`、`clearBinding`、`getSnapshot`、`openSource`、`pickMarkdownFiles`，以及显式授权与订阅操作。打开源文件仅接受已有绑定／预览引用和源位置，不接受任意命令。

source 状态至少区分 `loading / ready / missing / permission_denied / unsupported / scope_missing / unstable / error`。连接层另有 `connected / disconnected / incompatible / unknown_thread`，两者可以独立变化。

内嵌通信使用经过校验的 `Runtime.addBinding`／`Runtime.bindingCalled` 请求及 CDP 推送；`Runtime.evaluate` 只执行工具随构建发布的固定代码，数据序列化传入，不拼接 Markdown 或路径为脚本。方法依据见 [CDP Runtime](https://chromedevtools.github.io/devtools-protocol/tot/Runtime/)。

独立面板复用同一应用服务与组件，只通过受保护的本机 HTTP 接口交互，不复制一套绑定或任务状态机。候选服务消费可选的 SessionHints 契约；未提供日志 adapter 时仍完整支持目录扫描与手动路径。日志 adapter 只在 Codex 组合入口注入，不成为独立模式的启动依赖。

### 7.3 注入生命周期

每个确认可用的对话区域挂载唯一根节点，以 Shadow DOM 隔离样式；可识别但没有安全挂载点时不强插入宿主结构。面板不得遮挡输入、发送、审批和滚动操作。

重复注入是幂等的；导航或上下文重建先销毁旧实例再重建。卸载移除本工具节点、observer、监听与 binding，不修改其他插件的 DOM，也不改变宿主原有状态。iframe／其他应用／无关辅助窗口不能自动成为注入目标。

## 8. 启动、安全与兼容

只连接本机回环地址。验证实际监听地址、端口对应进程、应用路径／身份和 renderer target，不能仅因为 `/json/list` 返回数据就注入。默认候选端口 9341，可显式配置；端口占用时不接管未知进程。

没有端点但 Codex 已在运行时只提示正常退出后再调试启动；不强制退出、不杀进程、不循环重启。没有运行实例时，用户明确选择后才带调试参数启动。应用路径通过真实 `.app` 及元数据确认，不假设所有版本都叫同一个可执行文件。进程启动成功与端点可信、注入成功分别验证。

**回环不等于认证。** CDP 本身拥有读取页面、执行脚本等权限，工具的只读设计不会限制其他本机进程的 CDP 权限。停止工具／隐藏面板不会关闭仍在运行的 Codex 调试端口；需正常退出调试实例，再从普通入口启动。相关边界参考 [Dream Skin 安全说明](https://github.com/Fei-Away/Codex-Dream-Skin/blob/34335d27d54300eccb325cc652f6c93fef428b84/SECURITY.md)。

本工具额外实施：

- 本地 HTTP 仅监听回环，校验 Host／Origin，不开放通配 CORS。API 与订阅要求每次运行生成的随机凭证；浏览器首次打开可通过 fragment 交付后立即清除，不把凭证写入 URL 查询、磁盘或日志。
- CDP 请求限于已登记目标／上下文及当前展示版本；同名 binding 事件不是授权依据。校验消息大小、结构和操作白名单，禁止透传 shell、任意 CDP 方法或文件系统写接口。
- 文件授权以 `realpath` 校验，读取／打开前复核；自动候选不能扩展授权。项目外文件只在用户明确授权该文件或目录后读取。
- Markdown 默认安全文本渲染，不启用原始 HTML、不加载远程图片、不执行命令链接。源文件和会话内容均是不可信数据，不是工具指令。
- 不读取 `auth.json`、密钥、登录存储；不上传聊天／文件内容；诊断不记录原文、绝对私人路径或调试凭证。公开 fixture 使用合成数据或经用户确认的脱敏片段。

兼容性记录需含 macOS、CPU 架构、Codex 版本、实际应用路径规则、数据源位置规则、选择器、CDP 方法及脱敏 fixture。只声明实际通过的平台组合；未验证的 CPU／Codex 版本不能直接标记支持。复制第三方代码前核对许可证并保留必要声明，不能因“参考”而默认获得全部资产分发权。

### 12.1 入口与浮窗

- 在用户截图箭头所指工具栏位置，即加号／权限按钮这一组末尾插入 28px 高的轻量按钮。不得改写宿主按钮；挂载点只在 adapter 中定位；不明结构不猜位置。

- 点击打开顶层 popover，优先入口上方，视口边界自动避让；宽约 460px、最大不超过视口减 24px，高度不超过可用区域。滚动发生在窗内，打开前后输入框与宿主页面尺寸不变。
- 点击外部、Escape、关闭按钮均关闭；Escape／显式关闭后焦点返回入口，点击外部不抢走用户目标的焦点。切换对话关闭浮窗及未提交的选择，不串用路径或晚到回复。

### 12.2 一组 Markdown 的确认式绑定

- 支持单文件、多个 Markdown、授权目录内候选。macOS 提供系统文件多选，选中文件后仍只返回路径；授权＋预览＋确认后才监控。系统对话框取消不报错、不改绑定；非 macOS 或不可用时可每行输入一个绝对路径。
- 每个文件独立授权、预览、选择章节并显示错误；一个会话最多 16 份不同实际文件。同一文件的别名／符号链接不得重复计数；同一实际文件仅保留一个范围。权限验证不扩大到父目录。
- 已有文档与新预览构成草稿，可逐项移除；点击「确认绑定／确认更改」一次原子保存整组。任一新文档预览过期、源变化、授权失败、重复实际文件或版本冲突，整组不提交；取消保留旧绑定。移除全部需显式确认清空。
- 持久化 schema v2；读取旧 v1 单文件时保留 ID／范围／授权／版本，转换为一项数组，不丢历史。磁盘升级仅发生在后续成功事务；旧版本无法读取 v2，文档明确回退先备份。
- 每份文档独立快照与错误；缺失／权限失败不影响其他文档实时更新，正常文档合计＋缓存标记不隐藏问题。实际路径共享一个 watcher，每个监控身份仍单独校验授权。源文件打开携带所属文档 ID。
- 传输返回文档数组，兼容首项 binding／snapshot 只为现有单文档入口。整组输出有界；超出安全预算明确标记该项不可用，不以零项成功冒充完整合计。

## 13. 进度入口、焦点与可固定拖动浮窗（2026-09-26）

用户报告多路径输入和路径类型无法聚焦，并要求入口改为「进度」、百分比圆环、固定与拖动。本节覆盖 §12 中相应交互约定，不扩展文件读取授权。

- F01：浮窗内 input、textarea、select、checkbox 可通过真实鼠标和键盘操作；正常输入、复制粘贴、原生下拉不触发宿主编辑器聚焦或发送。隔离自有事件不禁止控件的默认行为，不修改宿主监听器。
- F02：工具栏显示「进度 已完成/总数」，图标为勾选比例圆环。比例仅来自已读取叶子项，零任务/未绑定不显示已完成；部分/缓存/断连明确标记，不能把部分数据填为有效总进度。不加入工作量估算或 ETA。
- F03：标题栏增加固定按钮与可访问的已固定状态。固定后外部点击、输入框交互不关闭浮窗；取消固定恢复外点关闭。关闭按钮始终有效；Esc 在浮窗内关闭，在原生 select 内交给下拉，在固定浮窗外不劫持宿主按键。切换会话销毁旧浮窗，固定和位置不串到其他会话，不承诺跨重启持久化。
- F04：按住标题栏非交互区域拖动；按钮和表单不启动拖动。边界为当前对话区域与可见视口交集，不能移入侧栏或另一对话。拖动后普通数据更新不吸回入口；视口/布局缩小时重新约束；指针取消、失焦、关闭、切换和卸载释放拖动资源。提供方向键移动的可访问拖动柄。
- F05：回归覆盖宿主 mousedown/pointerdown 聚焦干扰、真实表单操作、固定/取消/关闭、拖动边界/缩放/切换/清理、0/部分/全部/缓存比例。实际 Mac 另记录表单焦点与文字输入、固定和拖动结果，受控页面通过不替代真机结果。
