# 分隔线与多 CDP 共存

候选只在相邻文档之间显示线；空列表、单项和末项不添加底线。手动添加区保留单条区域分隔。

CDP 支持多个客户端，但共享 DOM、页面导航和调试状态。Task Lens 正常监控不导航、不暂停、不接管网络，只使用自己的隔离域、通信名和 shadow DOM；只能保护自己的操作，无法阻止其他客户端关闭宿主或改写 DOM。

## 同类实例互斥

启动运行时在连接前取得本机当前用户下的目标锁：`~/.codex-task-lens-targets/`，键由 Codex PID、端口和 target ID 组成，与数据目录和 profile 无关。活跃的另一 Task Lens 不被清理或替换。不同页面可独立连接；被占用的页面不会让其他正常页面断开。

正常停止/断线重连释放自己的锁；崩溃后只有确认记录 PID 已不存在才回收。身份损坏、权限不足或无法判断进程状态时保守拒绝。不终止锁中记录的进程，不修改第三方工具。锁是合作式互斥，不是针对同用户恶意进程的安全边界；旧版本不遵守新锁协议，不能与新版同时接管相同页面。
