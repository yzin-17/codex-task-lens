# 桌面会话扫描与文档范围交互修订

## 背景
当前 CLI 已支持 `--session-root ... --allow-session-read`，但桌面控制台没有入口；章节范围菜单仍可能被文档滚动区／确认底栏裁切；单个已选文档末尾仍有多余分隔线。

## 已确认需求
1. 桌面控制台提供“选择会话目录”和“停用扫描”。默认关闭，不隐式读取 `~/.codex`。
2. 选择目录后，将目录作为 `sessionRoot` 传入现有 SessionRecords，并显式设置 `allowSessionRead=true`；停用后删除配置并重启 Task Lens 运行时，不重启 Codex。
3. 会话扫描只读取所选根目录的 `sessions/` 与 `archived_sessions/` rollout JSONL 中明确 Markdown 路径，不读取 `auth.json`，也不授予任务文档读取权限。
4. 章节范围菜单进入浏览器 top layer，根据触发器、视口与固定确认底栏决定向上／向下展开；菜单自身滚动，不被祖先 overflow 裁切。
5. 已选文档仅在相邻项之间显示分隔线；单项和末项不显示底线。

## 数据与安全边界
桌面设置新增可选 `sessionRoot` 绝对路径。仅路径存在于配置中时启用会话读取。IPC 继续使用固定操作白名单和主 frame sender 校验。
会话目录读取失败不关闭 Task Lens；控制台和候选区域显示降级诊断，手动文件与项目目录扫描继续可用。

## 验收
- 控制台可选择、持久化、展示并停用会话目录；停用后运行时的 `allowSessionRead=false`。
- 打包应用仍无外部 Node/pnpm 依赖，preload 暴露的会话操作仅为固定 IPC 方法。
- 长章节列表在浮窗底部打开时位于确认底栏之上或可用空间一侧，搜索和键盘操作保持。
- 1 个已选文档无内部分隔线；2 个及以上仅相邻项之间有线。
- 不修改 Task 文档、不发送消息、不重启 Codex。
