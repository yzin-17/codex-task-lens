# 桌面会话扫描与文档范围交互修订

## 背景
CLI 与桌面控制台已具备会话目录扫描能力。用户进一步要求桌面版默认启用当前对话扫描，并让候选区的项目目录授权入口成为明确可点击的操作；既有章节范围浮层与分隔线修复保持。

## 已确认需求
1. 桌面控制台提供“选择会话目录”和“停用扫描”。默认启用 `${HOME}/.codex`；旧配置未声明扫描状态时也按启用迁移。用户明确停用后持久保持关闭，不因重启自动恢复。
2. 启用时将自定义目录或默认 `${HOME}/.codex` 作为 `sessionRoot` 传入现有 SessionRecords，并显式设置 `allowSessionRead=true`；停用只写入 `sessionScanEnabled=false` 并重启 Task Lens 运行时，不重启 Codex。
3. 会话扫描只读取所选根目录的 `sessions/` 与 `archived_sessions/` rollout JSONL 中明确 Markdown 路径，不读取 `auth.json`。对话中明确出现且真实存在的 `docs/tasks/**`、`tasks/**` 或 `TASKS.md` 可在未授权项目目录时直接作为候选展示；此阶段只做精确文件存在性/类型检查，不读取 Markdown 正文。
4. 章节范围菜单进入浏览器 top layer，根据触发器、视口与固定确认底栏决定向上／向下展开；菜单自身滚动，不被祖先 overflow 裁切。
5. 已选文档仅在相邻项之间显示分隔线；单项和末项不显示底线。
6. 若当前对话没有可用 Task 文档候选，候选区再显示明确的“授权项目目录”按钮作为扫描更多文档的可选入口；点击后切到目录模式、滚动到目录输入并聚焦，不自动授予任何路径。
7. 对话 Task 候选显示“待授权”；用户点击“添加”即视为明确授权读取这一份文件，创建单文件 grant 并预览，不授权其父目录，也不自动绑定；仍需底部确认后才改变监控绑定。

## 数据与安全边界
桌面设置包含可选 `sessionRoot` 绝对路径与 `sessionScanEnabled`。`sessionScanEnabled` 缺省为 `true`；启用且无自定义路径时使用 `${HOME}/.codex`。IPC 继续使用固定操作白名单和主 frame sender 校验。
会话目录读取失败不关闭 Task Lens；控制台和候选区域显示降级诊断，手动文件与项目目录扫描继续可用。

## 验收
- 控制台可选择、持久化、展示并停用会话目录；停用后运行时的 `allowSessionRead=false`。
- 打包应用仍无外部 Node/pnpm 依赖，preload 暴露的会话操作仅为固定 IPC 方法。
- 长章节列表在浮窗底部打开时位于确认底栏之上或可用空间一侧，搜索和键盘操作保持。
- 1 个已选文档无内部分隔线；2 个及以上仅相邻项之间有线。
- 有会话 Task 候选时无需项目目录授权即可列出候选；未选择前不读取正文，点击“添加”后仅授权该文件并形成待确认预览。
- 无会话 Task 候选时“授权项目目录”按钮视觉明确；点击后目录模式被选中且路径输入获得焦点。
- 不修改 Task 文档、不发送消息、不重启 Codex。
